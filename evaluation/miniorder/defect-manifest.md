# MiniOrder 私有缺陷清单

本文件仅供评估方使用，不得复制到 AI 可见目录。

| 私有构建身份 | 违反的需求 | Ground Truth | 预期证据 |
|---|---|---|---|
| `Baseline` | 无 | 满足全部 MiniOrder 业务需求 | 自动契约矩阵无失败 |
| `VariantA` | 需求 2：数量必须为 1～999 的整数 | 数量为 `0` 时被错误接受并可保存 | 表单金额可计算、保存成功、查询出现数量 0 的订单 |
| `VariantB` | 需求 2：订单金额为数量乘以单价 | 数量 `3`、单价 `12.50` 时错误显示并保存为 `15.50` | 只读金额和查询结果均显示错误金额 |

除表中单一目标差异外，其他契约必须与 `Baseline` 一致。若出现额外差异，该构建不得用于实验。
