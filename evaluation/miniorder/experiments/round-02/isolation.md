# MiniOrder 第二轮信息隔离说明

- 三个构建在正式运行前重新随机映射为 `target-01`～`target-03`，私有映射只保存在评估方产物目录。
- 每个目标目录只包含中性名称 `MiniOrder.exe` 和独立数据目录；路径不含 baseline、variant 或 defect。
- 健康检查和三个正式目标分别使用全新 projectless Codex 会话，不继承本评估会话或其他测试会话历史。
- 正式提示只包含中文需求、协议、正确工具入口和通用证据规则，不包含上一轮报告、具体触发输入、真值或版本身份。
- 测试方不得使用终端或文件系统；评估方审计其过程和最终报告是否违反边界。
- 同一 Windows 账户和主机不构成 OS 级强隔离。本轮结论只声称认知与流程隔离。
