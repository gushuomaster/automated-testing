# 本次隔离边界（组织侧候选）

正式 run_id=stop-live01-run01，仅测试上下文盲。准备方可以核对旧锁，但不得把实现历史传给测试方。新中性派发方 fork_turns=none，只读取即将冻结的 test-bundle 全文，再以 fork_turns=none 创建一个正式测试方。正式测试方只收完整业务需求、匿名程序窗口、完整工具文档、Schema、通用预算与停止规则，不收协议评估章节、历史报告、旧检查点、真值或旧轨迹。测试包正文必须完整一次交付，不能仅发文件路径、摘要或截断内容。

fork_turns=none 是上下文隔离，不是 OS 沙箱；工具能力没有物理删除，权限依靠指令和事后真实调用审计。单操作者窗口内用户、组织方和其他 Agent 不并发控制 MiniOrder；没有输入钩子或独占桌面，不宣称 OS 强制独占。组织方不向正式方发中途消息、业务提示、催问或纠正；派发方不回答业务问题、不发送健康轨迹，也不催促测试方。正式方不调用协作工具、不派生 Agent、不读文件/源码/内部数据/其他上下文。

健康使用 health-01，正式使用 run-01，数据目录各自独立；测试上下文不延续健康上下文，不接触健康路径。匿名目录不带构建/缺陷/真值身份，但组织侧知道同一样本，不能称全组织双盲或新软件泛化。

保留材料原始 UTF-8 字节 SHA256、字节数、原字符数和 LF 规范化字符数。读 API 可能规范化换行，字节哈希不等于派发明文逐字节证明。平台可能加密初始派发正文或隐藏部分消息；明确独立可核验的会话范围、实际派发字符数和限制，证据不足不冒称完整明文核验。原始报告与工具/会话记录先锁，之后独立审计；锁后评估关闭另记，不混入测试方输入。
