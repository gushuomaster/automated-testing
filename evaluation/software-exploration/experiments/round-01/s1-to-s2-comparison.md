# S1 -> S2 连接比较

## 输入可比性

S2-A 与 S2-B 都包含相同的 52 条需求描述、预期行为和 8 条歧义，需求标识与语义没有差异。S2-B 额外保留了 S1 的 `target`、`categories`、`conditions`、`information_nature`、`confidence` 和 `verification_status`，同时移除了本机绝对路径、模型响应和评估日志。因此，本轮没有观察到 S1 语义在中性交付时丢失。

## 结果比较

| 项目 | S2-A 核验输入 | S2-B S1 实际输出 | 差异 |
| --- | ---: | ---: | ---: |
| UI 映射召回 | 36/46（78.26%） | 43/46（93.48%） | B +7 条 |
| 映射精确率 | 36/36（100%） | 43/43（100%） | 均无错误正式映射 |
| 路径可复现 | 36/36（100%） | 41/43（95.35%） | 均达标；B 有 2 条保存后路径无执行证据 |
| 精确状态一致 | 35/52（67.31%） | 43/52（82.69%） | B +8 条 |
| GUI 动作 | 22 | 30 | B 多 8 次并耗尽预算 |
| 工具分类准确率 | INDETERMINATE | INDETERMINATE | 两轮均缺少独立冻结的逐次工具调用日志 |
| 人工介入 | 0 | 0 | 无差异 |
| 持久化副作用 | 0 | 0 | 无差异 |

S2-B 相比 S2-A 多保留为部分映射的主要是保存入口、保存后状态和既存结果映射。两轮由不同独立 Agent 执行，且实际动作数不同，因此不能把 B 的提升因果归因于 S1 额外字段，也不能据此声称 S1 输入优于人工核验输入。能确认的是：S1 实际输出没有妨碍 S2，在本轮还满足了全部冻结门槛。

两轮都把 REQ-046～REQ-048 判为 `UNREACHABLE`，显示共同的分类弱点：当完整验证需要禁止的重启或目录切换时，Agent 容易忽略已经观察到的公开查询状态，不会稳定地保留为 `PARTIALLY_MAPPED`。
