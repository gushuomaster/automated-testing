# S2 软件探索信息隔离说明

- 健康检查、S2-A 和 S2-B 使用三个独立且不继承历史的 Agent 上下文。
- S2-A 与 S2-B 使用不同数据目录和相同哈希的 MiniOrder Baseline 匿名副本。
- 正式测试窗口和路径不包含 `Baseline`、`Variant`、`defect`、`truth` 或历史实验目标身份。
- 测试方提示不包含源码路径、AutomationId 清单、真值映射、旧实验轨迹、用例、缺陷答案或评分结果。
- S2-B 输入只保留 S1 需求语义、来源片段标识和歧义；本机绝对路径、模型响应、运行日志和评估材料不进入输入包。
- 评估方在原始报告锁定前不向测试方读取或披露真值。
- 当前隔离依赖独立上下文和指令遵守；Agent 与评估方仍共享同一 Windows 主机，不构成 OS 级安全沙箱。
