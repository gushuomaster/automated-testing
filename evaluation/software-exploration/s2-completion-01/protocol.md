# S2 软件探索：现成 UIA 能力复用验证协议

本轮为同一 MiniOrder development/calibration 样本的新工具验证，不是未知软件的泛化成绩。目标是形成需求到入口、控件、状态及安全路径的可追溯映射，不设计业务测试、不判业务 PASS/FAIL、不报告产品缺陷。S2-A 使用核验需求，S2-B 使用真实 S1 输出；各一次独立上下文、独立程序和种子副本，不以成绩不理想重派。

## 输入与隔离

正式 Agent 可读取派发指定的启动指令文件本身，以及其中逐项列出的需求 JSON、报告 Schema、本协议、工具指南四个材料文件，须计算字节 SHA-256 后完整读取。只能启动组织方提供的固定 CLI 命令，并通过其 stdin/stdout 使用原生 UIA。启动参数及配置文件由组织方提供，Agent 不得打开配置、程序目录、源码、数据库、种子、历史报告、评分真值或其他文件，不得浏览网络、调用其他 GUI、运行任意脚本、调用子 Agent 或与其他上下文通信。只在最终答复输出原始 JSON 报告，由组织方保存。

独立上下文不继承组织方/实现方历史；A/B 不互传发现。隔离依赖指令、固定窗口门禁及事后真实会话审计，不是 OS 沙箱，也不能排除物理外部输入。若发现无法解释的输入变化，停止操作并记录，不推断为软件缺陷。

## 工具与动作边界

本轮复用 Windows-MCP 固定 UIA 子包；不启动其完整 MCP 服务。只导出绑定 HWND/PID 子树的公开 UIA、原生 Value/Selection/Focus/Expand/Collapse/Invoke。禁用截图、坐标和键盘回退。保存、删除、提交、导出、关闭等有持久副作用或结束软件的动作禁止。组织配置可精确放行“清空”“清除筛选”两个瞬时清理名称，既不是业务测试步骤，也不授权其他名称。

允许观察、页签选择、焦点设置、组合框展开/选择、瞬时字段设置、无持久副作用的查询及清理。不得为了验证业务规则主动执行缺陷触发用例、保存或重启；对依赖这些动作的需求，只映射已观察的安全前缀。

## 计时、预算、停止

每角色完整 task_started→task_complete 不超过 900 秒；GUI 原生输入最多 30 次，失败输入也计数；拒绝请求不算已发出的原生输入但须完整留痕。同一失败动作最多重试 2 次；初绑后最多重绑 1 次，本适配器固定窗口且不提供重绑，实际为 0。被动观察和语义 ack 不算输入。

组织方在派发前写入绝对 UTC 截止时间（派发时刻+900秒），CLI 同时用 UTC 和 monotonic 检查；该截止比实际 task_started+900秒保守。完整会话耗时仍单独核验，初始化、读材料和最终报告均计入，不以局部初始化时间替代。同步 COM 调用不能强行中断，若跨过期限，返回观察仍保留但不计为预算内支持证据；不得继续输入。报告也须在完整预算内结束。

首个业务输入前先形成需求驱动探索计划。每次只发一个输入，检查其自带的新快照，再显式确认结果。调用成功不是状态确认：必须指出目标属性/可见区域/选择等实际证据。冲突、无可区分证据或异常字段不能单独判软件问题。未决先 ack UNRESOLVED，仅一次纯 observe；仍未决再次 ack UNRESOLVED 后停止全部输入，清理也不豁免。不能用另一个主动输入验证前一个未知动作。观察已明确证实动作未生效可以确认“未生效”，须说明错误与回读依据，不能仅凭“没变化”猜测。

计划完成、预算耗尽、工具/环境无法恢复、副作用风险或停止门触发即结束。保留全部争议和工具失败，不以修改报告消除争议。报告只能总结截止前已有证据，不补跑。

## 输出与评分（运行前固定）

按原 Schema 输出 REQ-001～REQ-052 各一次。映射状态为 MAPPED、PARTIALLY_MAPPED、NOT_UI_OBSERVABLE、UNREACHABLE、INDETERMINATE；状态来自实际观察范围，不能把未执行状态当已到达。保留首批计划、探索调整、控件清单、逐动作前后状态/执行状态/证据引用、未知项和限制。persistent_side_effects 只填实际发生的持久副作用，未发生填 []；“未观察到”说明写 summary，不作为一条副作用。GUI动作数量及耗时自报由真实日志复核。

沿用原门槛：关键入口召回100%，UI需求映射召回≥90%，正式映射精确率≥95%，声明路径复现率≥95%，无依据控件比例≤5%，持久副作用0。46个UI相关项与6个非UI项由原真值独立裁决；PARTIALLY_MAPPED计入正式映射但不算完整业务能力。安全前缀和完整声明路径分别统计。A/B分别评分，不平均掩盖失败。

原始最终答复、完整会话、工具事件、动态启动包先按字节锁定，再对照真值逐项裁决，另副本独立复验声明路径。Schema、范围、预算、语义门、通信和输入隔离均单列严格合规条件；数值门槛达标不等于全协议通过。无真实停止分支时记 NOT_EXERCISED，不用没有违规证明停止能力。旧评分器对工具分类缺日志的固定说明本轮不适用，保留旧输出并另附逐调用裁决；不修改旧评分器或历史成绩。

## 相对旧轮的实质变化

由 Sky 改为固定 Windows-MCP 原生 UIA；去除坐标/键盘；新增窗口、预算、确认与未决停止程序门；工具文档及材料从限定文件完整读取核对哈希；清理精确授权由配置冻结。本轮不使用旧协议的 focus-only 主动核验例外：任意输入结果仍未知均只能一次纯被动复核，仍未知即停止。规划/映射仍由新 Agent 自主完成。不能把两轮描述为条件相同的重复实验，不能将改善单独归因于某个因素。原程序、业务需求、种子、输入包、Schema、时间/动作预算及映射评分规则保持不变。
