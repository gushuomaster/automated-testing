## 关闭原因

1. 失败主因是 Agent 未遵守确定性流程规则（未决后停止、时间/输入预算、通信限制），这类规则应由执行框架代码强制，而非继续用提示词考核模型。
2. 纯 UIA、禁截图的自设约束不适用于"普遍的陌生 C/S 软件"（自绘控件、画布、UIA 不完整的界面）。
3. 共享桌面导致多次来源不明的输入干扰，裁决成本过高。
4. MiniOrder 为自建样本，继续在其上细化无法回答陌生软件可行性。
