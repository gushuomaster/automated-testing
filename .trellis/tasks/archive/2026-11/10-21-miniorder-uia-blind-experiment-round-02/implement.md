# MiniOrder 第二轮 UIA 独立盲测实验执行计划

1. 核验 round-01 锁定哈希并新增收尾勘误与实验索引。
2. 冻结 round-02 协议、基线、隔离说明、匿名映射和测试提示。
3. 组装三个匿名运行目录并执行 allowlist、EXE 哈希和种子哈希检查。
4. 在独立 projectless 上下文完成最小 UIA 健康检查；失败则保留阻塞证据并停止正式运行。
5. 顺序启动三个匿名目标，各用新的 projectless 测试会话完成正式盲测；标准化处理允许的重启请求。
6. 原样保存报告并锁定哈希，全部完成后揭示私有映射评分。
7. 输出 round-02 独立评估和两轮对比，验证编码、哈希、进程清理、OpenSpec 和 Git 状态。

## 停止条件

- 测试线程接触禁止信息：该轮作废并留痕，不反复更换会话追求成绩。
- 程序、需求、种子、预算或评分权重发生漂移：停止并重新冻结。
- 正确入口按规定恢复后仍连续失败：记录工具/环境阻塞，不由评估方代做业务测试。
- 不自动提交、推送、发布或归档。
