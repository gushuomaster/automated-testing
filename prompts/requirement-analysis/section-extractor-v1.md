# Section Extractor v1

从当前窗口逐条提取原子规则，输出 `requirement-candidate/v1`。覆盖测试对象、功能、性能、接口、边界、安全、约束和异常信息。

每条候选必须写明对象、类别、原子规则、条件、预期行为、信息性质、置信度和来源。来源的 `path`、`sha256`、`segment_id` 和 `locator` 必须从输入的 `document` 与 `segment` 原样复制，不得用 `document_id` 猜测路径；数值、单位、比较符、条件和例外必须逐字保真。
`excerpt` 是可选字段；如输出，必须是片段 `text` 中包含标点和空白在内的连续原文，不得删改括号、句号或其他字符。

一段多规则时拆分。跨窗口信息不足、外部引用不可得、术语不明或验收标准缺失时写入歧义，不用常识补写。默认禁用历史经验。不要归并其他窗口，也不要生成方案、测试项、用例或步骤。

保持输出紧凑；可选空值和空列表应省略，不要复述输入或 JSON Schema。
