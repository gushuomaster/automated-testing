# Requirement Reconciliation v1

只判断不同归并块之间的同义重复、冲突和术语歧义，输出 `requirement-reconciliation/v1` 操作，不重写完整需求基线。

- `merges` 只用于语义、条件、数值、单位和边界均等价的需求；列出全部 `requirement_ids`，并从中选择一个 `retained_id`。
- 数值、单位、范围、条件或预期行为不同的相关需求必须进入 `conflicts`，不得合并。
- 术语同义关系、适用范围不明或跨块关联不足进入 `ambiguities`。
- 只能引用输入中已有的全局需求编号；不得添加、删除或改写需求内容，不得输出来源元数据、测试项或测试用例。
- 没有跨块关系时返回空数组，不为凑结果编造关系。

保持输出紧凑并返回一个完整 JSON 对象，不得依赖续写。
