# S1 冻结评估口径

## 人工真值与原子化

真值使用 `ground-truth/v1`。每条真值必须包含：唯一编号、单一可判断规则、主类别、规则陈述、来源片段、原子化依据和关键数值/单位/边界 token。一个陈述包含可独立通过或失败的多个行为时拆分；只有条件与结果共同构成一个判断时保留在同一条。

正式运行要求至少两名独立复核者。两人分别给出输出需求到真值的匹配，不读取对方决定；一致结果由程序确定性归并，不一致结果标记 `disputed`，等待预注册裁决者处理，不能自动取平均。

## 匹配状态

| 状态 | 分值 | 口径 |
| --- | ---: | --- |
| `complete` | 1.0 | 对象、规则、条件和预期完整匹配，关键 token 保真 |
| `partial` | 0.5 | 核心规则正确但缺少非关键条件，仍可识别对应真值 |
| `no_match` | 0 | 无对应真值或规则错误 |
| `duplicate` | 0 | 重复覆盖已匹配真值，不增加召回 |
| `disputed` | 0（待裁决） | 独立复核不一致；在裁决前按保守值进入未解决项 |

关键数值、单位、比较关系或合法边界被改写时，即使语义大致相同，也记录关键保真错误，正式结果不能通过。

## 指标及分母

- 精确率：所有正式输出需求所得匹配分之和 / 正式输出需求数；未裁决输出按 0 计入分母。
- 召回率：每条真值取得的最高匹配分之和 / 真值需求数；重复输出不能重复增加分子。
- F1：上述精确率和召回率的调和平均。
- 来源定位有效率：来源定位经复核有效的正式输出数 / 正式输出需求数。
- 无依据输出比例：`no_match` 或没有裁决记录的正式输出数 / 正式输出需求数。
- 功能、性能、接口分别使用本类别输出和真值作为各自分母，不用总体平均分掩盖类别失败。

每个指标保存 numerator、denominator 和 value。部分分、未解析内容、未匹配真值、未匹配输出、争议和关键错误保留在逐条明细中。

## 通过门槛

只有角色为 `formal` 的独立运行才计算通过与否。功能、性能、接口的精确率和召回率均须不低于 80%，来源定位有效率不低于 95%，无依据输出比例不高于 5%，关键保真错误和未裁决项均为零。校准、开发和回归运行的 `passed` 固定为空，不得换名后混入正式成绩。

## 隔离与锁定

正式协议在运行前固定材料哈希、真值哈希、匹配规则哈希、模型、Skill、提示哈希、调用/token/修订预算、允许输入和禁止路径。分析 Agent 输入包通过隔离审计，不得包含真值、历史答案、源码或评分日志。

原始报告和证据使用 `report-lock/v1` 锁定文件路径、字节数和 SHA-256；锁定后再评分。文件发生任何变化时验证失败，必须保留旧结果并建立新版本，不能覆盖后重算。
